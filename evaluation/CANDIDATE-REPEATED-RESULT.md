# 三臂三次重复实验复核

实验目录：candidate-campaign-20261116-170824-7333。同一道已暴露开发题，各容量三次，固定 Top-1、Top-2、Top-3 顺序。同模型 DeepSeek 评审，不是独立人工验收。原始结果不修改。

## 观测结果

- Top-1：自动复评 0/3 通过，三次均完成研究并发布一张卡片，但都选择权限系统文档，没有回答候选筛选是否授予权限。第二次 why 还错误地回答“可以”，属于主题混淆及过度推断。平均工作流耗时约 31.93 秒。
- Top-2：自动复评 2/3 通过。三次都研究两个候选并发布一张卡片；第一次已研究正确工具筛选文档，却仍发布权限系统文档。另两次发布正确文档，并用直接引文回答两项事实。平均工作流耗时约 38.86 秒。
- Top-3：自动复评 0/3 通过，但原因不同。第一次研究生成出现输出截断，后续达到每项模型请求预算，三个候选均未提交完整研究，最终 partial 且无卡片。第二次多次提交无效引用并触及预算，最终虽完成三项研究并发布一张卡片，仍为 partial；发布的也是权限系统文档。第三次完成研究并发布正确工具筛选文档，裁定写明“筛选只改变模型可选的工具集合，不授予执行权限”，自动答案覆盖评审却认为“改变集合”不等于“限制候选”。后者有过严误拒倾向，保留语义争议；summary 将筛选模式称为权限模式也有术语风险，不能无条件把整卡改为通过。平均工作流耗时约 79.97 秒。

三臂工作流平均已报告/估算费用分别约 0.009652、0.012171、0.018284 美元。这里不含独立执行的语义评分费用，也不是完整供应商账单。九次均保留实际研究数量、未发布处置、卡片与预算拒绝日志。

## 不能得出的结论

不能将本次计数当作总体准确率，也不能直接宣称 Top-3 更差或 Top-2 已达到稳定生产水平。增加 K 改变了研究工作量及模型自主批次安排；在相同每项预算下，工具修复与引用错误的成本也不同。两次 Top-3 的执行完成度不足，与第三次的语义评分争议不能混成同一种答案失败。

与此前首轮烟测分开解释，不为了提高通过率把两次实验选择性合并。固定顺序、单题重复、同模型评分和小样本都限制结论。

## 后续工程优先级

1. 保留本实验，不继续为同一道题追加重复。Top-2 仅作为下一轮候选配置，不自动修改生产默认值。
2. 区分“研究候选召回成功”与“最终选择正确材料”。Top-2 第一次已召回却发布错主题，说明发布前仍需任务对齐检查；不能只靠增加 K。
3. 检查研究批次与单项预算的计费范围、无效引用重试及长度截断的止损。维持现有硬上限，不能仅增加预算使实验变绿。
4. 保留 Top-3 第三次为语义等价困难反例。后续新增校准样例时，使用独立编写的等价与近似但不充分表述，避免直接将当前模型输出追补为标准答案。
5. 修复后再在相邻主题题组做小规模验证。尚未运行新的真实实验，不宣称已解决上述问题。
