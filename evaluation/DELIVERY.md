## 使用方法

在安装了 Linux 依赖的 WSL/Linux Node 24 仓库根目录运行。

```sh
npm run eval:calibrate
npm run eval:auto
npm run eval:tasks -- --compare --repeat 3
npm run eval:auto -- --security --reliability
npm run eval:capture -- --input RESULT_DIRECTORY --out NEW_REVIEW_DIRECTORY
```

网页入口为 /#/evaluations，或点击顶栏“评测中心”。旧的已启动服务需使用新代码启动后才会显示该入口。隔离库中的 sweepId 只属于对应实验，页面按实验和 trial 读取结果。
