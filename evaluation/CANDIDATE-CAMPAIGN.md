# 多候选研究对照交付

实现日期：2026-11-16。此前 Top-K 仅为评分回放；本入口实际调用生产 workflow 执行选材、研究、证据核验和发布。默认免费模拟，真实调用必须显式 --live。

## 对照定义

固定任务、候选原文、参考时刻、模型、提示模板、评分器和一张交付卡片，仅改变 researchCandidates 为 1、2、3。所有臂使用同一提示模板，模板中的 K 参数及冻结研究计划按臂变化，这是干预本身。每个被选入研究计划的候选必须完成研究，之后才能发布。已研究但未发布的替代项保留 finding 和 not_published 处置，不删除研究成本。

研究与发布容量分离，默认配置为 0，保持旧行为。启用后上限 3，不提高既有每项模型请求、全局请求或证据限制。没有足够相关候选时实际研究数可以小于 K，报告记录实际数，不将空位伪造为研究成功。证据不足的报告可记录明确弃答；未完成研究或预算失败不能被静默丢弃成已完成。

comparison.json 校验各臂输入和源码相同，记录实际选中/研究数量、卡片数、处置、原始评分、语义复评、耗时及报告/估算/未知费用。各臂固定执行 K=1,2,3，不是随机试验；小样本与已暴露题不能代表总体准确率。

## 运行

在已有依赖和 Node 24 的 WSL 副本中，免费对照：

```bash
npm run eval:candidates
```

真实烟测：

```bash
npm run eval:candidates -- --live
```

脚本需要时隐藏提示输入 OpenRouter 和 DeepSeek 密钥。默认 pilot-02、三个臂各一次；包含同模型 DeepSeek 语义复评，不会重复整套评分器校准。会消耗 Jev、主/研究模型及评分器费用。OpenRouter 侧核验 1 美元以内剩余额度；DeepSeek 官方费用另计，没有跨供应商美元硬上限。技术错误时脚本停止并打印部分产物目录；质量失败会被保留到对照，不为获得全绿而中断或篡改。

烟测确认执行无故障后，再运行三次重复：

```bash
REPEATS=3 npm run eval:candidates -- --live
```

合成配对题先免费验证：

```bash
npm run eval:tasks -- --config evaluation/experiment.adjacent.json
```

指定合成题做真实三臂烟测的例子（不自动跑 12 题全套）：

```bash
CAMPAIGN_CONFIG=evaluation/experiment.adjacent.json CAMPAIGN_TASK=adjacent-1-1 npm run eval:candidates -- --live
```

当前同模型评分与模型辅助裁决沿用用户授权，humanReviewed=false；不得当作独立人工验收。完整真实 Top-K 对照尚未执行，不应仅凭免费模拟选择最终生产策略。
