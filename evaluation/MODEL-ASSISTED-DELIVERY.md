## 一条命令执行剩余同模型 API 验证

在已启用 Node 24 的 WSL 项目目录执行：

```bash
bash scripts/eval-tasks/same-model-review.sh
```

脚本必要时隐藏输入 DeepSeek 密钥，默认使用 deepseek-flash；若 DNA_MODEL 已设置则沿用它，也可通过 DNA_JUDGE_MODEL 显式指定。先运行 36 条语义校准，再仅复评三个历史实验共九个 trial（含空候选）。校准任何样例未达到模型辅助参考预期时，脚本停止，保存校准产物，避免在未校准的评分器上继续消费。不得为通过校准而直接抄评分器输出改参考标签。

这会调用 DeepSeek 官方 API 并产生费用，coverage-separated-v3 将答案覆盖与证据支持分为两次调用，最多约 90 个评分请求，每个输出上限 3000 token；结构失败和无必答事实的样例会跳过模型调用。请求设置 thinking disabled，无模型层重试。原始 Agent 的采集、研究、Jev 和发布不重跑。DeepSeek 官方消费不受 OpenRouter --max-usd 限制，此脚本不提供美元硬上限。

本轮自动化进程读取不到用户终端里的 DEEPSEEK_API_KEY，因此没有执行付费校准或虚构结果。脚本不要求把密钥发到聊天里。

验证结果：11 项评审、预算及原始产物保护测试通过；v4 的 48 条结构回归全部符合预期；v4 七题免费端到端回归完成，6 个 needs_review、空候选题 passed，无技术错误。另修复了免费后端加载真实模型配置时的模型 ID 映射冲突。以上均不等于 DeepSeek 语义校准已通过。

## 后续正式实验

### 首次 DeepSeek 语义校准与修复

test-results/same-model-review-20261115-230359-3106/calibration 为首次真实校准：23/36 匹配参考，falsePass=0，technicalErrors=0。脚本按门槛停止，尚未进入历史实验复评。该结果是评分器与模型辅助校准参考的一致率，不能表述为 Agent 准确率。

不一致样例包含同义改写、漏答和偏题。评分模型多次把 requiredFacts 的参考文本当作答案，返回的 answerSpan 在实际答案中不存在；片段校验拒绝这些结果，保留 needs_review。没有为提高一致率修改参考标签。

现采用 evidence-ids-v2：输入将要求与真实答案单元分离，不再传 acceptedTexts；模型从 A 编号的实际答案单元和 Q 编号的有效引文选择证据。不存在的编号仍不能通过，漏答仍需失败，来源中有事实不能代替答案已说出事实。保留旧片段格式校验以兼容已有测试与历史解析。9 项评分及原始报告保护测试通过，尚未付费验证修复后的 36 条校准结果。
